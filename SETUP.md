## Detailed Setup Steps

### 1. Clone Repository
```bash
git clone <your-repo-url>
cd 16660-BioBuzz
```

### 2. Run Automated Setup
```bash
chmod +x setup.sh
./setup.sh
```

**Options:**
- `./setup.sh --ci` — CI mode (non-interactive, fails on any error)
- `./setup.sh --no-android` — Skip Android SDK check (for JVM tests only)

### 3. Configure Local Properties
```bash
cp local.properties.template local.properties
# Edit local.properties with your SDK path
```

**local.properties.template:**
```properties
# Auto-generated by setup.sh - EDIT THIS FILE
sdk.dir=/Users/yourname/Library/Android/sdk
# OR on Linux: sdk.dir=/home/yourname/Android/Sdk
# OR on Windows: sdk.dir=C\\:\\Users\\yourname\\AppData\\Local\\Android\\Sdk
```

### 4. Open in Android Studio
1. **File > Open** → Select `16660-BioBuzz` folder
2. **File > Sync Project with Gradle Files** (or click elephant icon)
3. Wait for Gradle sync to complete (bottom status bar)

### 5. Connect Robot & Run
1. Connect Robot Controller phone via USB
2. Enable USB Debugging on phone (Settings > Developer Options)
3. Select run configuration: **BioBuzz Autonomous** or **BioBuzz TeleOp**
4. Click **Run** (green play button)

## Common Issues & Fixes

### "SDK location not found"
```bash
# Ensure local.properties exists with correct sdk.dir
echo "sdk.dir=$HOME/Library/Android/sdk" > local.properties
# OR on Linux:
echo "sdk.dir=$HOME/Android/Sdk" > local.properties
```

### "Gradle sync failed: Could not find kotlin-serialization"
```bash
# Ensure root build.gradle has serialization plugin:
# classpath "org.jetbrains.kotlin:kotlin-serialization:$kotlin_version"
# And TeamCode/build.gradle has: apply plugin: 'kotlinx-serialization'
```

### "Could not find dev.nextftc.v2:control:0.2.0"
```bash
# Add maven repositories to TeamCode/build.gradle:
repositories {
    maven { url 'https://repo.dairy.foundation/releases' }
    maven { url 'https://maven.brott.dev/' }
}
```

### "Java version mismatch / Unsupported class file major version"
```bash
# Use JDK 11 or 17 (not 21+)
export JAVA_HOME=$(/usr/libexec/java_home -v 11)  # macOS
# OR
export JAVA_HOME=/usr/lib/jvm/java-11-openjdk    # Linux
```

### "adb: device unauthorized"
1. On phone: Settings > Developer Options > USB Debugging > **Allow USB Debugging**
2. On phone: Accept the RSA fingerprint prompt when connecting
3. Run `adb devices` — should show `device` not `unauthorized`

### "Build fails with 'Duplicate class' errors"
```bash
./gradlew clean
./gradlew :TeamCode:assembleDebug
```

- **JVM Tests** — Runs on every push/PR

## Development Workflow

### Making Changes
1. Edit Kotlin files in `TeamCode/src/main/java/...`
2. Run JVM tests: `./gradlew :TeamCode:test`
3. Build APK: `./gradlew :TeamCode:assembleDebug`
4. Deploy to robot via Android Studio

### Adding New OpModes
1. Create new class in `TeamCode/src/main/java/org/firstinspires/ftc/teamcode/`
2. Annotate with `@Autonomous` or `@TeleOp`
3. Add to `AndroidManifest.xml` if needed (usually auto-detected)

### Calibration Workflow
Run **Calibration Wizard** OpMode on robot:
1. Select "Calibration Wizard" from Driver Station
2. Follow 9-step guided flow:
   - Hardware probe
   - Drivetrain measurements (tape measure)
   - Dead wheel verification
   - Flywheel RPM vs distance
   - Camera extrinsics
   - HSV color ranges
   - AprilTag verification
   - Export calibration.json
